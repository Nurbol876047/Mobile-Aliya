# 🌿 FloraCare — фото арқылы өсімдік денсаулығын бақылау (Flutter · Dart)

Жапырақтың фотосын жүктеп, өсімдіктің күйін ЖИ арқылы бағалайтын және скан
тарихын жүргізетін мобильді қолданба. Интерфейс үш тілде: **қазақша, орысша,
ағылшынша** (профильден ауысады, ЖИ де сол тілде жауап береді).
**Бір код базасы — Android және iOS.** Алдын ала қарау үшін веб-нұсқа да жиналады.

```
flora_care/
├─ lib/
│  ├─ main.dart                 # кіру нүктесі
│  ├─ core/
│  │  ├─ logic.dart             # бизнес-логика (UI-сыз, толық тестіленген)
│  │  ├─ analyzer.dart          # фотоны оқу, тексеру, кішірейту (isolate)
│  │  ├─ ai.dart / ai_service.dart  # Gemini: промпт, JSON-схема, тексеру, желі
│  │  ├─ models.dart            # Plant, Observation
│  │  ├─ repo.dart              # қойманың ортақ интерфейсі
│  │  ├─ sqlite_repo.dart       # Android/iOS: SQLite (sqflite), 3 кесте
│  │  ├─ prefs_repo.dart        # веб-алдын ала қарау: JSON қоймасы
│  │  ├─ photo_store*.dart      # фотоны құрылғының жеке қалтасына сақтау
│  │  └─ web_camera*.dart       # браузердегі камера (getUserMedia), телефонда — жүйелік
│  ├─ data/catalog.dart         # өсімдіктер анықтамалығы (27 түр, фото + күтім)
│  ├─ l10n/l10n.dart            # үш тілдің мәтіндері, tr('кілт')
│  ├─ state/app_state.dart      # ортақ күй (ChangeNotifier)
│  └─ ui/                       # экрандар мен виджеттер
├─ test/logic_test.dart         # бизнес-логика тесттері (шеткі жағдайлармен)
├─ test/ai_test.dart            # ЖИ жауабын тексеру, промпт, тіл нұсқауы
├─ test/ai_card_test.dart       # ЖИ карточкасының виджет-тесті
├─ test/l10n_test.dart          # үш тілдің толықтығы, қолданылған кілттер
└─ docs/SPEC.md                 # техникалық сипаттама, деректер моделі, қауіпсіздік
```

## 1. Орнату

Қажет: **Flutter SDK 3.24+** (Dart 3.4+).

```bash
flutter pub get
flutter doctor        # ортаның дайындығын тексеру
```

## 2. Іске қосу

**Android (эмулятор немесе құрылғы):**
```bash
flutter devices
flutter run -d <device_id>
```

**iOS (тек macOS):**
```bash
cd ios && pod install && cd ..
flutter run -d <iphone_simulator_id>
```

**Браузерде алдын ала қарау (деректер браузерде сақталады):**
```bash
flutter run -d web-server --web-port 8080
# немесе: flutter build web && (cd build/web && python3 -m http.server 8080)
```

**Тесттер:**
```bash
flutter test
```

## 3. Құрастыру

**Бір код — барлық жерде.** `main`-ге push жасалғанда бәрі осы `_src/` қалтасынан жиналады:

| Қайда | Қалай жиналады |
|---|---|
| Render (сайт + API) — https://floracare-backend-ynkm.onrender.com | `render.yaml` → `scripts/build_web.sh` |
| GitHub Pages — https://nurbol876047.github.io/Mobile-Aliya/ | `.github/workflows/pages.yml` |
| Android APK | `.github/workflows/android.yml` → Artifacts |
| iOS | `.github/workflows/ios.yml` → Artifacts |

Жергілікті компьютерде сайтты Render-дегідей ашу (жоба түбірінде):
```bash
bash scripts/build_web.sh && python3 backend/server.py   # http://127.0.0.1:8090
```

**Android APK / AAB:**
```bash
flutter build apk --release          # build/app/outputs/flutter-apk/app-release.apk
flutter build appbundle --release    # Google Play үшін
adb install -r build/app/outputs/flutter-apk/app-release.apk
```

**iOS (.ipa).** Apple iOS қолданбасын **тек macOS-та** құрастыруға рұқсат етеді —
Linux/Windows-та `flutter build ipa` жұмыс істемейді. Үш жол бар:

| Жол | Не қажет | Нәтиже |
|---|---|---|
| Mac-та өзіңіз | macOS + Xcode (тегін) | `flutter build ipa --release` → симуляторда/өз құрылғыңызда іске қосу |
| Бұлттағы macOS (GitHub Actions) | GitHub тіркелгісі | `.github/workflows/ios.yml` → Artifacts: `floracare-ios-unsigned` (.ipa) және симуляторға арналған `.app` |
| App Store / TestFlight | Apple Developer Program ($99/жыл) | TestFlight сілтемесі немесе App Store-да жариялау |

Қолтаңбасыз (`--no-codesign`) .ipa-ны iPhone-ға орнату үшін оны өз Apple ID-іңізбен
қайта қолтаңбалау керек: **Sideloadly** немесе **AltStore** (тегін Apple ID — қолданба
7 күн сайын жаңартуды талап етеді; ақылы Developer тіркелгісімен — 1 жыл).
Xcode бар Mac-та ең қарапайымы: `open ios/Runner.xcworkspace` → Signing & Capabilities-те
өз Apple ID-іңізді таңдау → Run.

**iPhone-да бірден ашу (құрастырусыз, Wi-Fi арқылы):**
```bash
python3 backend/server.py 0.0.0.0                       # ЖИ сервері (8090)
cd _src && flutter build web --dart-define=AI_BACKEND_URL=http://<компьютердің_IP>:8090 --output=build/web-lan
python3 -m http.server --directory _src/build/web-lan 8081 --bind 0.0.0.0
```
Телефоннан `http://<компьютердің_IP>:8081` ашып, Safari-де **«Үй экранына қосу»**
(Share ▸ Add to Home Screen) десеңіз, қолданба өз белгішесімен, Safari панельдерінсіз
ашылады. Ескерту: браузердің камерасы тек HTTPS-та жұмыс істейді, сондықтан бұл режимде
фотоны «Галереядан» таңдаңыз (ЖИ, тарих, анықтамалық — бәрі жұмыс істейді).
iOS үшін `ios/Runner/Info.plist` ішінде камера мен фотокітапхана рұқсаттарының
мәтіні (`NSCameraUsageDescription`, `NSPhotoLibraryUsageDescription`) тұр.
Android үшін камера рұқсаты `image_picker` арқылы сұралады; Android 13+ жүйесінде
галереядан таңдау үшін қосымша рұқсат қажет емес (жүйелік таңдағыш пайдаланылады).

## 4. ЖИ талдауы (Google Gemini)

Фотоны **Google Gemini** талдайды: диагноз, денсаулық бағасы (0–100), жапырақ
түсінің жіктелуі (сау жасыл / сарғаю / қоңырлану үлесі), байқалған белгілер,
ықтимал себептер, 4–6 қадамдық кеңес, болжам, өсімдік туралы деректер мен күтім
талаптары, шұғылдық деңгейі. Жауап **таңдалған тілде** (қазақша / орысша /
ағылшынша — сұранысқа `lang` беріледі), қатаң JSON-схема бойынша келеді және
қолданбада қайта тексеріледі (`lib/core/ai.dart`).

Қолданбада шаблон/болжам нәтижелер жоқ: ЖИ жауап бермесе, нәтиже көрсетілмейді
(«Қайталау» түймесі шығады), ал әлі талданбаған өсімдік «Әлі тексерілмеген» деп
белгіленеді. Алғаш ашқанда тізім бос — демо деректер енгізілмейді.

Екі режим бар (`--dart-define` арқылы таңдалады):

| Режим | Баптау | Кілт қайда | Қашан |
|---|---|---|---|
| **Сервер арқылы** (ұсынылады) | `AI_BACKEND_URL=http://...:8090` | тек серверде (`.env`) | әрқашан |
| Тікелей | `GEMINI_API_KEY=...` | APK ішінде (шығарып алуға болады!) | тек оқу демосы |

**Серверді іске қосу** (жоба түбірінде, тек стандартты Python):
```bash
echo "OPENAI_API_KEY=сіздің_кілтіңіз" > .env     # бір рет
python3 backend/server.py                          # http://127.0.0.1:8090
FLORACARE_HOST=0.0.0.0 python3 backend/server.py   # телефоннан Wi-Fi арқылы қосылу үшін
```

**Қолданбаны ЖИ-мен іске қосу:**
```bash
cp secrets.example.json secrets.json   # мекенжайды өзіңізге қарай өзгертіңіз
flutter run --dart-define-from-file=secrets.json
# браузерде: flutter build web --dart-define-from-file=secrets.json && (cd build/web && python3 -m http.server 8080)
# кең экранда қолданба телефон корпусының ішінде көрсетіледі (lib/ui/widgets/phone_frame.dart)
```
Мекенжай: браузер/десктоп — `http://127.0.0.1:8090`, Android эмуляторы —
`http://10.0.2.2:8090`, нақты телефон — компьютердің Wi-Fi IP-і (мыс. `http://192.168.1.5:8090`).

`secrets.json` пен `.env` `.gitignore`-да тұр — репозиторийге түспейді.

## 5. Пайдаланушы нұсқаулығы

| Әрекет | Қалай |
|---|---|
| Фото сканерлеу | «Сканер» (немесе басты беттегі «Фото сканерлеу») → «Камерадан» / «Галереядан» → «Сканерлеу». Алдын ала өсімдік қосу міндетті емес |
| Камера | «Камерадан» камераны бірден ашады: браузерде — қолданба ішінде (тікелей көрініс + түсіру түймесі, рұқсат сұралады), телефонда — жүйелік камера. Рұқсат берілмесе, түсінікті хабарлама мен «Галереядан» түймесі шығады |
| Сақтау | Нәтиже **автоматты түрде тарихқа** сақталады; өсімдікке тіркеу міндетті емес |
| Тіркеу | Сканнан кейін «Қай өсімдікке тіркеу?» — бар өсімдікті таңдаңыз немесе «＋ Жаңа өсімдік» (атауы ЖИ-ден алдын ала толтырылады) → «Өсімдікке тіркеу». Кейінірек «Тарих» бетіндегі «Тіркеу» арқылы да болады |
| Нәтиже | ЖИ диагнозы, денсаулық бағасы, белгілер, себептер, кеңестер, болжам, өсімдік туралы және күтім + түс пайыздары |
| Анықтамалық | «Өсімдіктер» → «Анықтамалық» қойындысы: 27 өсімдік (фото, сипаттама, күтім, уыттылық) → «Менікіне қосу» |
| Өсімдікті қолмен қосу | «Өсімдіктер» → «＋» → атауын енгізіңіз (міндетті) |
| Тілді ауыстыру | «Профиль» → «Тіл» → Қазақша / Русский / English (ЖИ де сол тілде жауап береді) |
| Іздеу | «Тарих» → іздеу жолағы (өсімдік атауы немесе жазба бойынша) |
| Сүзу | Күй бойынша чиптер және кезең (7 / 30 күн / барлығы) |
| Сұрыптау | Күні, атауы, күй ауырлығы, жасыл үлесі + кему/өсу ретімен ауыстыру |
| Тарих | Өсімдікті ашыңыз: жасыл үлесінің диаграммасы және барлық скандар |
| Жою | Тарихтағы себет белгісі немесе өсімдік бетіндегі «Өсімдікті жою» (расталады) |

**Жақсы фото үшін:** жарық жерде, жапырақ кадр ортасында, бір түсті фонда.
Бағаны толығымен ЖИ береді — бұл көмекші ақпарат, нақты медициналық диагноз емес.

## 6. Неліктен Flutter/Dart?

- Бір Dart код базасынан **Android (APK/AAB) және iOS (.ipa)** құрастырылады,
  интерфейс екі платформада бірдей көрінеді (Material 3).
- Сурет өңдеу (`image`), камера/галерея (`image_picker`), жергілікті дерекқор
  (`sqflite`) үшін тұрақты ресми пакеттер бар.
- Ауыр есептеу `compute()` арқылы бөлек isolate-та орындалады — интерфейс қатып қалмайды.
- Бизнес-логика таза Dart модулінде, сондықтан `flutter test` арқылы
  эмуляторсыз тексеріледі.
